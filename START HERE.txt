Extract the whole ZIP. Keep the folders together.

WINDOWS
First time: Windows → 1 - SETUP CARDVISION.bat
Then use the black/gold CardVision Counter Dev desktop icon.
Backup: Windows → 2 - START CARDVISION.bat

MAC
First time: Mac → 1 - SETUP CARDVISION.command
Then open Mac → CardVision Counter.app (black/silver chip).
Backup: Mac → 2 - START CARDVISION.command

USING IT
1. Save your rules and your seat in Settings.
2. Choose the SportsBetting browser window and click Connect.
3. Scanning starts. Wait for TABLE: AUTO-ALIGNED.
4. It finds the dealer, player areas, active-seat panel and totals automatically.

LIVE FEED OUTLINES
5. The feed shows where it is looking for cards and totals.
6. Click Edit outlines. Drag a box to move it; drag its white handles to resize.
7. Use the outline menu to select tiny totals. Click Done editing to save.
Video stays live while you edit; scanning pauses, then returns to its prior state.
Your changes follow automatic alignment. Reset selected/all restores defaults.

HITS AND SPLITS
Hits can extend the card crop into nearby space. Red means clipping/overlap: adjust it.
Two split stacks get separate hands and totals, without recounting the original pair.
If needed, drag each pink split-total box onto that hand's total badge.
Manual fallback: select the seat in Manual Correction and enter 8 3 / 8 K.
Unclear splits or more than two split hands stay under review.

NO calibration boxes are required to get started.
NO round number required.
NO shuffle region required.

Find table again retries automatic alignment.
Pause scanning stops reading without clearing the count.
New hands are detected when a visible table clears, then cards reappear.
New shoe still resets the shoe count manually when an actual new shoe starts.
Next hand remains a fallback if the clear-table interval was missed.
